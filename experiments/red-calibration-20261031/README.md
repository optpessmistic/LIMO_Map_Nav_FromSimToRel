## 归档内容

- `blank-01.tar.gz`：第一尝试全部 80 个普通文件。
- `batch-12-01.tar.gz`：第二尝试全部 154 个普通文件，含失败帧，未丢弃拒绝原因。
- `fixtures.tar.gz`：12 个 SDF、离线真值、manifest；采集器没有读取离线真值。
- 两个 `*-runtime-source.tar.gz`：执行草稿、测试及其随附记录。
- `archive-manifest.json`：每个归档成员的原路径、长度和 SHA-256；记录未跟随/未打包的 ROS `latest` 符号链接，真实日志普通文件已打包。
- 两份 `*-batch.json`、`rejected-sample-002.json` 和 PNG：方便直接查看的原样副本。
- `SHA256SUMS`：归档及上述副本的校验表，不包含此 README 或校验表自身。

所有 tar 成员均通过解压读取的逐文件 SHA-256 与原文件复核，不执行归档里的脚本。运行版本的 CameraInfo 要求精确同戳；没有以邻近帧的标定或新采样修补失败样本。
