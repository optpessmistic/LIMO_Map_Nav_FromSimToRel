# 用户手册核对

依据用户提供的 106 页 LIMO 产品用户使用和开发手册，按 PDF 页序引用。手册描述 Jetson Nano 标准 LIMO，包含 ROS1 示例；用户另行确认项目使用 ROS2，因此以下 launch 名只作为对应手册版本的依据，不能当作 Jazzy 指令执行。

| PDF 页 | 核对内容 | 对本项目的影响 |
|---|---|---|
| 6 | 标称外形 322×220×251 mm，阿克曼最小转弯半径 0.4 m，Jetson Nano 4G，EAI X2L，DaBai 或 D435；系统栏写 Ubuntu18.0 | 确认旧硬件资料范围；实际传感器需核实，不能据此认定车上 ROS2 发行版 |
| 18–20、40–41 | 四轮差速、阿克曼、履带、麦轮模态及切换 | 初版采用差速，真实机械模态需与软件一致；差速可原地转向 |
| 36–39 | 底盘驱动；ROS 速度接口 geometry_msgs/Twist 的 cmd_vel | 自主算法通过导航和统一速度控制层使用接口，不同时启动多个串口驱动 |
| 47–49 | 雷达启动及 GMapping 建图 | 已有 SLAM 实现，不需要从零编写建图算法 |
| 49–50 | Cartographer 及位姿图/地图保存 | 区分占据地图与可继续优化的 SLAM 状态 |
| 51–54 | move_base、AMCL、规划器与固定地图导航 | 这里是 ROS1 且主要为已知地图导航；未知环境需要探索调度和在线 SLAM |
| 55–63 | DaBai / D435、RGB-D、RTAB-Map | 相机有不同版本；图像内参、深度单位、RGB 深度对齐和 TF 必须实测 |

已逐页阅读相关文本，并渲染核对第 6、48、51 页的表格和指令。手册原文没有被提交到公开仓库。

实现选择以实际 ROS2 环境及上游源码核查为准，详见 [上游审计](upstream-audit.md)。例如当前公开 ROS1 源码与手册在 `limo_start.launch` 参数上就有差异，不能跨镜像照抄。
