# 红色替身的可重复标定场景

`tools/build_red_calibration.py` 生成 12 个静态 Gazebo 场景，用于测量目前红色 RGB-D 检测器的距离、角度、遮挡与实例区分能力。识别接口保持可替换；正式课程物品尚未确定。

| 场景 | 要测的问题 |
|---|---|
| 空场景 | 无目标时是否误报 |
| 正面 0.4 / 0.8 / 1.6 / 3.2 m | 检出率、有效深度及表面定位误差随距离的变化 |
| 0.8 m、方位 ±35° | 靠近图像边缘时能否检测 |
| 表面入射角 45° / 75° | 斜视导致像素减少与深度变化的影响 |
| 大红色平板 | 红色像素是否被误当成指定薄盒替身 |
| 间距 0.18 m 的两个红盒 | 检测及地图融合能否区分相邻实例 |
| 部分遮挡 | 可见部分减少时的漏检与定位偏差 |

距离指相机中心到红盒正面中心的水平距离，不是光轴深度。正样本沿用当前迷宫的 0.03×0.06×0.20 m 红盒，背靠灰色支撑。大红色平板只在这个受控薄盒实验中定义为负样本；它不替代正式物品定义，现有颜色检测器可能将其检出。两个目标的 0.18 m 间距小于当前 0.30 m 融合半径，刻意用于暴露实例合并问题。

## 生成

在仓库根目录运行。下面使用本机 F 盘已有模型源码；其他工作区把两条 Xacro 路径改为自己的 vendor 路径。

```bash
/usr/bin/python3 tools/build_red_calibration.py \
  --output outputs/red-calibration/new-fixtures \
  --model-xacro /mnt/f/study/Personal_Plan/LIMO_Map_Nav_FromSimToRel/vendor/hunter_gazebo/src/limo_base/urdf/limo_four_diff.xacro \
  --sensor-xacro /mnt/f/study/Personal_Plan/LIMO_Map_Nav_FromSimToRel/vendor/hunter_gazebo/src/gazebo_harmonic/urdf/limo_gazebo.xacro
```

输出目录必须尚不存在。`worlds/` 保存 SDF，`offline_truth/` 保存独立评分真值，`manifest.json` 记录源码与场景摘要、样例清单和几何检查。机器人节点只订阅传感器，不读取真值目录。

生成器从当前支持的固定相机结构提取名义位姿和内参；不能解析的相机旋转、额外 sensor/camera pose 或自定义投影会报错。每个场景检查物体实体相交、起点净空、背板贴合/承托、目标朝向、视锥裁切及解析射线遮挡。实际物理沉降、渲染自遮挡和有效深度仍须在 Gazebo 中测量。

## 实际采集

使用 [有界采集工具](../tools/red_calibration/README.md) 加载生成的 manifest。默认只输出计划；显式 `--execute` 才启动场景。单次先用 `--case 01_blank` 检查链路，再用 `--all` 顺序执行 12 场景。每场景固定保存首先收到的六组新同步 RGB-D，拒绝和空检测也保留；采集过程不读取 `offline_truth`。

2026-10-31 的 `blank-01` 单场景实际通过：六组输入、CameraInfo 和精确时刻 TF 有效，全部检测结果为空；36 个图像/深度产物的长度和 SHA-256 独立复核一致，六个自有进程组均确认退出。该结果只验证空场景采集链路，不证明物品不存在或有效搜索范围。运行使用迁入版本管理前冻结的草稿，原样源码及哈希随采集保存；受版本管理的入口见上面的工具说明。

## 验证状态与下一步

24 项生成器纯测试覆盖正常场景及破坏几何的反例。首次实际批次 `batch-12-01` 在第二场景停止：空场景 6/6 有效；0.4 m 场景 5 个有效样本各检出一个候选，第 2 帧缺双方同戳 CameraInfo，检测未运行。后十场景未运行。[首次失败记录](../experiments/red-calibration-20261031/README.md)与生成时的 manifest 保持原样。

已将采集改为先冻结固定窗口，再运行检测及保存派生文件。新的 `deferred-center-01` 单场景六帧有效；随后 `deferred-batch-12-01` 的 12 场景全部执行，72 帧均具有有效 RGB-D、双方同戳 CameraInfo 和精确 TF。完整批次用时 720.513 wall 秒，所有自有进程组退出，无强制终止。离线审计逐文件核对哈希并保留 12 场景/72 帧分母，全部具备描述性计数对照条件。90 项采集、runner 与审计纯测试通过。详见[新实验与原始证据](../experiments/red-calibration-deferred-20261031/README.md)。

空场景六帧均无候选；各单盒场景（0.4–3.2 m、±35°、45°/75°斜视、部分遮挡）六帧均有一个检测。相邻双盒六帧各有两个检测，但原地图融合回放只留下一个确认记录；一对一关联候选在相同输入下保留两个，尚未接入生产或在线验证。大红色平板六帧也各产生一个检测，说明当前颜色基线不能区分指定薄盒和其他红色物体。

这是一组固定光照、固定视角的短窗，不是跨场景识别准确率、有效搜索距离或视觉覆盖认证。相邻六帧不能当作六次独立实验；原生模型快照仅验证 ID/数量，未测实际相机世界位姿或物理静止，故不报告绝对位置误差。采集循环中的同步阻塞路径已消除，但旧失败没有回调时序记录，不能断言其唯一根因已被证明。

接下来优先修复同帧目标关联，并为自主观察真正接受的帧增加源端留存，再验证有限多朝向观察流程。正式目标定义保持可替换；需要跨布局重复实验及实测位姿证据后，才能选择可靠观察距离与站位间距。当前不发布完整搜索成功声明。
