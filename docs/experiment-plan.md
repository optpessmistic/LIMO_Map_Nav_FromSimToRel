# LIMO 迷宫实验验收方案

本项目的最终交付是实车和 Gazebo 中可复现的未知迷宫搜索任务。二维格网基线只检查决策逻辑。以下验收值是项目初始建议，待按场地、目标尺寸、课程要求和实车性能确定。

## 任务定义

用户与课程 PPT 已确认正式验收为“完整探索可达迷宫、搜索数量和位置未知的多个目标、在建成的地图中标注、返回启动位置”，使用 ROS2，不需要拿取。目标物品、实车相机型号与实车 ROS2 发行版待查；开发机已确认 WSL Ubuntu 24.04，采用 Jazzy/Harmonic。“发现目标立即返航”仅保留作对照实验，不能用它满足正式验收。

“未知”是机器人启动时不读取完整地图、目标坐标、仿真模型状态或规划路径。Gazebo 的世界文件仅供仿真器使用。地图真值和目标真值可由独立评估器读取，不进入探索器或检测器。

## 分阶段验收

| 阶段 | 交付及通过条件 | 当前状态 |
|---|---|---|
| M0 版本与接口 | 确认底盘、Ubuntu、ROS、相机；录下 scan、odom、RGB、camera_info、TF；确认运动模式 | 手册已核对，实车待采集 |
| M1 手动建图 | 在封闭小迷宫低速遥控一圈；地图结构与实际一致；保存地图与数据包 | 已运行自主 SLAM；此项手动实车基线待运行 |
| M2 定点导航 | 固定地图上 5 个目标点往返；无碰撞、无 TF 双发布；停止命令有效 | 在线建图中的目标导航已验证；独立固定图/实车测试待运行 |
| M3 自主探索 | 无预载地图，SLAM 和导航同时运行；能退出死胡同并进入未探索分支 | run14 小迷宫四次探索成功，无剩余可达前沿；多布局待复测 |
| M4 目标感知 | 正样本确认、干扰目标拒绝、遮挡不误判；保存图像、时间戳和目标位置，在最终地图中标注 | run14 两个红盒替身匹配；正式目标、干扰与覆盖测试待完成 |

## 测试矩阵

先用 3 张开发迷宫调参，再固定参数测试 5 张未用于调参的迷宫，每张至少 3 个目标布置或启动朝向。预算允许时扩展到 30 次以上。每次保存 seed、地图与目标布置、各仓库 commit、配置、启动命令、事件日志、数据包、地图、目标证据和终止原因。

| 场景 | 应观察到的行为 |
|---|---|
| 单通道及死胡同 | 有序探索、无原地无限尝试、成功返航 |
| 环形走廊及相似路口 | 完成闭环，目标和 home 坐标随地图优化保持一致 |
| 起点附近就有目标 | 即返模式及时结束；全图模式继续探索 |
| 目标在转角后或朝向背面 | 扫视或补充视点后识别，不因激光已覆盖就跳过 |
| 多个相似物品 | 只接受目标 ID 或目标类别与实例规则 |
| 目标缺席或不可见 | 报告搜索范围及未找到，不能宣称目标不存在 |
| 一条返航路被封 | 重新规划；无可行路时明确 return_failed，不能直接成功 |
| 无可达 frontier 但仍有未探区 | 报告 blocked/incomplete，不能等同完整建图 |
| 相机或激光中断、TF 过期 | 暂停任务并停止运动，保留恢复/失败原因 |
| 时间或电量预算不足 | 提前返航，报告 budget_return，不计找物成功 |

## 指标与判定

1. **完整任务成功率**：任务要求全部达成次数 / 全部测试次数，同时报告分母。返航成功但未找到物品单列，不算完整成功。
2. **地图覆盖率**：与独立真值对齐后，统计起点连通且车体可达的真值自由空间中被观测为自由的比例。实车采用测量平面图或独立参考地图；没有参考地图时只报告代理量，不将 frontier 耗尽标为 100%。初始目标 ≥95%。
3. **视觉搜索覆盖与标注**：需记录视点、朝向、视场、遮挡和可识别距离。二维逻辑基线的理想可见性不作为实车相机覆盖率。最终提交原始地图 YAML/PGM、带目标标记的可视化图及独立目标记录 JSON，包含目标身份、map 坐标、观测时间、地图标识和证据图像；标记不能画入占据栅格而改变规划障碍物。
4. **身份准确性**：按目标类别/ID 统计误检和漏检；连续确认必须来自不同时间帧，同一张图重复发布不增加证据。
5. **目标定位误差**：目标估计点与实测点的距离；若只有二维框，没有深度、已知尺寸或多视几何，就不计三维定位完成。初始目标 ≤0.20 m。
6. **返航误差**：实际底盘相对启动位姿的平移和航向误差，建议初始门槛 ≤0.15 m、≤15°。action 的 SUCCEEDED 还需与测得位姿核对；精确停靠可在起点增加独立标记。
7. **效率**：首次发现耗时、总耗时、探索与返航各自路程、重规划和恢复次数、CPU/内存、图像推理延迟。分别报告中位数和最差值，必要时给分位数。
8. **碰撞与终止状态**：碰撞次数必须为 0；记录 timeout、not_found、exploration_blocked、localization_lost、return_failed，不删除失败运行。

## 仿真到实车

Gazebo 先采用与实车一致的差速底盘、雷达高度、相机位姿和话题。按序加入里程计误差、测距噪声、图像遮挡、照明变化、消息延迟及滑移；避免同时改多个参数。所有节点统一使用模拟时间，实车关闭模拟时间。

迷宫墙应高于雷达扫描平面；通道必须容纳车体及转向包络。手册标称 322×220 mm 的矩形底盘对角线约 0.390 m，原地旋转需要考虑此包络及定位误差，不能只按 220 mm 车宽选通道。最终 footprint 以实测传感器、外壳和轮胎突出部分为准。首轮可用约 0.6 m 或更宽通道，线速度 0.15 m/s 作为待验证起点。

实车先人工监护低速试验。独立的速度仲裁与看门狗负责失联停止；遥控、探索、返航不可直接同时写到底盘 cmd_vel。此要求直接服务于本项目的运动控制和成功判定。
